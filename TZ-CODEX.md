#### S1. Единый формат денег и процентов

**Файлы:** `src/components/Simulator.tsx` (строки 82, 374, 375, 437, 439, 440, 442, 502, 609),
`src/components/TradeApp.tsx` (строка 44)

**Что сейчас.** В приложении **семь** разных форматов чисел:

| Место | Код | Результат |
|---|---|---|
| шапка | `balance.toLocaleString("en-US", { maximumFractionDigits: 2 })` | `$23,644.1` — **1 знак** после запятой |
| метрика «Цена» | `currentPrice.toFixed(2)` | `$65496.98` — **нет разделителя тысяч** |
| журнал, колонки «Вход/выход», «Stop», «Результат» | `Number(...).toFixed(2)` | `$65496.98` |
| текст ошибки о нехватке средств | `notional.toLocaleString("en-US", { maximumFractionDigits: 2 })` | `нужно $2,188, доступно $23,644.1` |
| ось Y | `formatPrice` → `toLocaleString("en-US", …)` | `65,300` |
| тултип | `money()` → `toLocaleString("en-US", …)` | `$65,496.98` |
| легенда OHLC | `toLocaleString("ru-RU", …)` | `65 599,48` |

Итог: на одном экране `$23,644.1`, `$65496.98`, `65 300` и `65 599,48` — четыре разных вида одного
и того же числа. Для учебного продукта, где пользователь считает риск в процентах от баланса,
это прямой источник ошибок.

**Что сделать.**
1. Создать `src/lib/format.ts` с **единственными** хелперами:
   ```ts
   const money = new Intl.NumberFormat("ru-RU", { minimumFractionDigits: 2, maximumFractionDigits: 2 });
   export function formatMoney(value: number) { return `$${money.format(value)}`; }
   export function formatPercent(value: number, digits = 2) {
     return `${value.toLocaleString("ru-RU", { minimumFractionDigits: digits, maximumFractionDigits: digits })}%`;
   }
   ```
   `style: "currency"` **не использовать** — в `ru-RU` он подставит символ рубля; валюта доллар,
   префикс `$` ставим вручную.
2. Заменить **все** семь мест на эти хелперы, включая ось Y и тултип.
3. `formatPrice` (ось Y) оставить с параметром `decimals`, но перевести на `ru-RU`.
4. `formatSigned` для P&L — тоже через `formatMoney` с явным знаком.

**Критерий приёмки** (снять скриншот, сверить):

#### S8. Производительность `GET /api/trades`

**Файлы:** `src/app/api/trades/route.ts`, `supabase/migrations/`, `supabase-schema.sql`

**Что сейчас.** Замер в браузере: `GET /api/trades` → **1 640–1 959 мс**. Причина — **три
последовательных** round-trip к удалённому Supabase (≈ 500–600 мс каждый):

1. `requireUser()` — выборка сессии + пользователя одним JOIN,
2. `getActiveSession()` — выборка сессии со снимком,
3. `tradesQuery` — выборка сделок.

**Что сделать.**
1. Написать Postgres-функцию, возвращающую всё нужное **одним** вызовом:
   ```sql
   create or replace function public.get_trades_dashboard(p_user_id uuid, p_scenario_id text)
   returns jsonb
   language plpgsql security definer set search_path = '' as $$
   declare v_session public.simulation_sessions%rowtype; v_user public.app_users%rowtype; v_trades jsonb;
   begin
     select * into v_user from public.app_users where id = p_user_id;
     if not found then raise exception 'user not found'; end if;
     select * into v_session from public.simulation_sessions
      where user_id = p_user_id and scenario_id = p_scenario_id and status = 'active'
      order by created_at desc limit 1;
     select coalesce(jsonb_agg(t), '[]'::jsonb) into v_trades from public.trades t
      where t.user_id = p_user_id and t.scenario_id = p_scenario_id
      order by t.created_at desc;
     return jsonb_build_object(
       'session_id', v_session.id,
       'candle_index', coalesce(v_session.current_candle_index, 0),
       'candles', v_session.candles,
       'market_source', v_session.market_source,
       'balance', v_user.balance,
       'trades', v_trades);
   end; $$;
   ```
   + `revoke all on function … from public, anon, authenticated;`
   + `grant execute on function … to service_role;`
2. Переписать `GET /api/trades` на этот RPC. Формат ответа **не менять** (фронтенд и `disser_prod`
   зависят от полей `trades`, `session_id`, `candle_index`, `candles`, `market_source`, `balance`).
3. Замер после: `GET /api/trades` ≤ **800 мс**.

**Критерий приёмки**
- Один сетевой вызов вместо трёх.
- Ответ API совместим с текущим (все шесть полей на месте, формат `trades` — массив объектов).
- Латентность ≤ 800 мс (замерить из вкладки браузера, как в предыдущих проверках).
