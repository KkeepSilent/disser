## Зависимости

Используйте Node.js 20+ и pnpm. В корне проекта выполните:

```bash
pnpm install
```

## Переменные окружения

Скопируйте [шаблон](../.env.example) в `.env.local`. Указывайте адрес проекта целиком, включая `https://`.

| Переменная | Обязательность и назначение |
|---|---|
| `SUPABASE_URL` | Обязательна; адрес Data API проекта |
| `SUPABASE_SECRET_KEY` | Серверный ключ `sb_secret_…`; обязателен при отсутствии legacy-ключа |
| `NEXT_PUBLIC_SUPABASE_URL` | Опциональна; в шаблоне, текущий серверный клиент её не читает |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Опциональна; в шаблоне, текущий клиент её не использует |
| `SUPABASE_SERVICE_ROLE_KEY` | Поддерживаемая замена `SUPABASE_SECRET_KEY`; отсутствует в шаблоне |

Секрет читается только на сервере. `NODE_ENV` задаёт Next.js и использует для флага Secure у cookie. См. [серверный клиент](../src/lib/server/supabase-admin.ts).

## База и демонстрационный вход

1. Для чистого проекта выполните [полную схему](../supabase-schema.sql) в Supabase SQL Editor. Последние миграции уже включены в этот файл.
2. Для существующей рабочей БД определите, каких изменений не хватает, и примените соответствующие [миграции](../supabase/migrations) в порядке имён. Сначала проверьте их на копии базы.
3. Для новой демобазы выполните [seed для SQL Editor](../supabase/seed-editor.sql). Он создаёт или сбрасывает `edu` с балансом $25 000 и ролью администратора. Альтернатива — подключиться через `psql` и выполнить `\i supabase/seed.sql`, затем ввести пароль в приглашении.
4. Выполните `pnpm dev`. Откройте [локальный адрес](http://127.0.0.1:3000/) и войдите как `edu`. Для стандартного сида пароль `123`; при запуске через `psql` используйте введённый пароль.

## Команды

| Команда | Действие |
|---|---|
| `pnpm dev` | Сервер разработки на порту 3000 |
| `pnpm build` | Production-сборка |
| `pnpm start` | Запуск готовой сборки, локально `pnpm start -p 3000` |
| `pnpm lint` | ESLint по проекту |
| `pnpm typecheck` | TypeScript без записи JS |

Команды определены в [package.json](../package.json). Типовые сбои — в [диагностике](troubleshooting.md).

## Известные ограничения

- Стандартный демопароль предназначен для локальной проверки. Перед публикацией задайте другой пароль. [ТЗ 1A.8](../TZ-FIX-BUGS.md#1a8-сид-пользователь-edu--123-с-ненулевым-балансом)
- Если занят порт 3000, сначала определите владельца порта. [ТЗ, раздел 0.6](../TZ-FIX-BUGS.md)
