## Частые проблемы

| Симптом | Что проверить |
|---|---|
| EADDRINUSE | Найдите процесс на 3000. Используйте уже работающий экземпляр TradeMind или остановите известный процесс перед запуском. |
| Белая страница или ошибка загрузки | Проверьте терминал Next.js, обновите текущую вкладку. Dev и build используют общий каталог .next, поэтому запускайте сборку после остановки dev. |
| 503 или Invalid supabaseUrl | Проверьте URL с https://, серверный ключ и перезапуск после правки .env.local. |
| 401 | Повторите вход, проверьте срок и домен cookie. |
| 403 на маршрутах пользователей | Нужна роль admin. |
| 409 при открытии сделки | Сверьте баланс. Если сервер сообщает об изменении цены, обновите страницу перед повтором. |
| Резервный учебный сценарий | Проверьте доступ к Binance с хоста. Действующая сессия хранит свой снимок до перезапуска. |
| Нет свечей | Дождитесь завершения загрузки, проверьте ответ GET /api/trades и консоль браузера. |
| tsc ссылается на удалённый маршрут в .next/types | Перегенерируйте артефакты Next.js чистой сборкой. |
| Нет таблицы или RPC | Сверьте применённые миграции, Data API и серверный ключ. |

~~~powershell
Get-NetTCPConnection -State Listen -LocalPort 3000
curl.exe -I http://127.0.0.1:3000/
~~~
