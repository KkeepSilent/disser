## 2. Принципы планирования

1. **Сначала читаемость, потом ноль.** Любая фича, которая делает интерфейс нечитаемым, чинится до того, как добавляется новая.
2. **Данные в БД — источник истины.** Клиент не пересчитывает деньги; он отображает то, что вернула БД.
3. **Бесплатно.** Только бесплатные публичные API, без ключей и без платных сервисов.
4. **Документация вместе с кодом.** Изменение поведения без правки `docs/` не считается сделанным.
5. **Каждый месяц заканчивается работающим состоянием** — не «почти готовым», а рабочим.

## 4. Milestones подробно

### M1–M3 · Ноябрь 2026 — «График читается, данные актуальны»

**Цель месяца:** приложение выглядит как торговый терминал и не врёт про цены.

| Скоуп | Пункты ТЗ |
|---|---|
| Свечи занимают ≥ 55 % полосы, объём стоит под свечами | 2F.3 |
| Стоп-лосс не сдавливает ценовое действие (clamp домена) | 2F.1 |
| Плейсхолдер стопа явно называет уровни стопа | 2F.4 |
| Ценник на оси не перекрывает подписи уровней | 2F.2 |
| Кнопка «Обновить данные» + дата снимка в интерфейсе | 2C.2, 2C.3 |
| Нет мигания старых цен при смене сценария | 2C.4 |
| Единый формат денег | 2C.5 |
| `getMarketCandles` не дёргается без нужды | 2C.6 |
| `/api/market/candles` под авторизацией | 2C.7 |
| Контраст WCAG AA для подписей и ошибок | 2C.9, 2A.3 |
| Порог «крупной позиции» в % от капитала | 3.12 |

**Критерии выхода**
- Свечной график визуально сопоставим с TradingView по BTCUSDT.
- Стоп на 5 % от цены виден и при этом свечи занимают ≥ 60 % высоты поля.
- Любая цифра в интерфейсе совпадает с рыночной (допуск 1 %) либо явно помечена как учебная.
- Lighthouse accessibility ≥ 1.0.

**Зависимости:** нет. Это блокирует всё остальное по графику.

### M5–M7 · Декабрь 2026 — «Живой рынок, часть 1»

**Цель месяца:** цена обновляется сама.

| Скоуп | Пункты ТЗ |
|---|---|
| WebSocket Binance напрямую из браузера + fallback REST | 2D.2 |
| Автообновление цены, графика, метрик; индикатор Live | 2D.3 |
| Вход в сделку по серверной live-цене, гард свежести | 2D.4 |
| Разделение кэша и equity, mark-to-market | 2D.4 |
| Документация: `market-data.md`, `simulator.md`, `chart.md` | 2G |

**Критерии выхода**
- Цена обновляется не реже 1 раза в секунду без нажатий.
- Формирующаяся свеча двигается в реальном времени.
- При обрыве WS — явная индикация, backoff-переподключение, рабочий fallback.
- Расхождение цены на экране и в БД > 0.5 % приводит к `409`, а не к сделке по чужой цене.

**Риск:** Binance недоступен из части регионов → fallback обязателен, а не опционален.

### M8–M10 · Январь 2027 — «Живой рынок, часть 2 + риск-контроль»

| Скоуп | Пункты ТЗ |
|---|---|
| Серверный singleton: одно WS-подключение, проверка всех стопов раз в 1–2 с | 2D.5 |
| Стоп срабатывает **при закрытой вкладке** | 2D.5 |
| Режим «Учебный сценарий» с автоплеем (свеча сама каждые N секунд) | 2D.6 |
| Переключатель режимов, live по умолчанию | 2D.6 |
| Equity, нереализованный P&L, «до стопа %/$», время в позиции | 2D.7 |

**Критерии выхода**
- Открытая позиция со стопом закрывается сама, даже если пользователь закрыл вкладку.
- Нагрузка на БД не растёт с числом пользователей (O(1) проверок на тик).

**Риск:** требуется long-running хостинг вместо serverless → решение по деплою принимается в декабре.

**Решение требуется:** LMS-часть (уроки/прогресс) — это расширение скоупа MVP. Если ресурса не хватает — либо сильно урезаем до «урок = одна страница», либо переносим на май. Не делать «наполовину».

## 5. Риски и что делаем

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Binance API недоступен из части регионов | высокая | среднее | Fallback REST + CoinGecko/Kraken, индикатор источника в UI (2D.2) |
| Live-режим требует long-running хостинга | средняя | высокое | Решить в декабре; при невозможности — стопы проверяет клиент, ограничение фиксируется в README |
| Объём live-режима (2D) больше, чем MVP | высокая | высокое | Жёсткий порядок: 2D.2 → 2D.3 → 2D.4 → 2D.5. Если не влезает — останавливаемся на 2D.4, учебный режим остаётся рабочим |
| Документация отстаёт от кода | высокая | среднее | Правило: изменение поведения без правки `docs/` не завершено; проверка в CI (ссылки) |
| Растёт количество дефектов без регресса | средняя | высокое | Тесты и CI с февраля; до этого — ручной чек-лист из ТЗ |
| Нет ресурса на LMS-часть (уроки/прогресс) | средняя | среднее | Принять решение в январе: делаем урезанно или переносим на май |
| Расхождение «цены на экране» и «цены в БД» | средняя | высокое | Гард свежести (2D.4) + фиксация P&L по цене исполнения |

## 6. Осознанно не делаем до мая

- Мобильное приложение и PWA.
- Пуш-уведомления и email.
- Мультиязычность интерфейса (только русский).
- Социальные механики, реферальная программа, лидерборд.
- Несколько бирж и валютных пар (только BTC/ETH/SOL к USDT).
- Тикер-символы, спот-торговля, вывод средств — продукт **учебный**, реальной торговли нет.
