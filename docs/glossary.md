## Рынок и сделки

| Термин | Значение |
|---|---|
| Свеча / OHLC | Открытие, максимум, минимум и закрытие за интервал |
| Тело | Диапазон от открытия до закрытия |
| Фитиль | Диапазон от минимума до максимума |
| Объём | Объём торгов за интервал |
| Long / Buy | Позиция выигрывает при росте цены |
| Short / Sell | Позиция выигрывает при снижении цены |
| Стоп-лосс | Уровень защитного закрытия |
| Тейк-профит | Уровень закрытия для фиксации прибыли |
| Номинал | Цена × количество |
| Маржа | Обеспечение для позиции |
| Кэш / balance | Денежный остаток счёта |
| Equity | Стоимость счёта с учётом оценки открытых позиций |
| Mark-to-market | Оценка позиции по текущей цене |
| P&L | Прибыль или убыток |

## Данные и доступ

| Термин | Значение |
|---|---|
| RLS | Политики доступа к строкам PostgreSQL |
| RPC | Вызов функции Postgres через API |
| SECURITY DEFINER | Выполнение функции с правами её владельца |
| Снимок | Зафиксированный набор свечей для одной сессии |
| Fallback | Резервный учебный набор свечей |
| Кэш данных | Временное хранение результата запроса |
| TTL | Срок действия, после которого значение истекает |

## Известные ограничения

Тейк-профит, отдельный расчёт equity и live-обновления пока отсутствуют. [ТЗ 2D](../TZ-FIX-BUGS.md).
