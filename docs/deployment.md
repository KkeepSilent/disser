## Сборка

На хостинге нужны сборка и серверный Next.js с Route Handlers. Текущий режим обрабатывает события по запросам, поэтому подходит serverless с поддержкой Next.js. В production нужен HTTPS для Secure-cookie.

Локальная проверка собранной версии после остановки dev-сервера:

~~~bash
pnpm build
pnpm start -p 3000
~~~

Адрес для локальных проверок — [127.0.0.1:3000](http://127.0.0.1:3000/).

## Конфигурация

Задайте серверные переменные из [руководства](getting-started.md#переменные-окружения) в нужном окружении хостинга. Проверьте SQL-схему в staging до обновления приложения. Сиды локального администратора не используйте для публичного запуска.

| Заголовок | Значение |
|---|---|
| X-Content-Type-Options | nosniff |
| X-Frame-Options | DENY |
| Referrer-Policy | strict-origin-when-cross-origin |
| Permissions-Policy | camera=(), microphone=(), geolocation=() |

[Конфигурация Next.js](../next.config.ts).

## Известные ограничения

Серверные стопы при закрытой вкладке потребуют постоянно работающего обработчика рынка или эквивалентного фонового сервиса. Нынешняя сборка проверяет стопы при ручном шаге. [ТЗ 2D.5](../TZ-FIX-BUGS.md).
