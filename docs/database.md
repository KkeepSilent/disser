## Таблицы

| Таблица | Данные | Кто пишет |
|---|---|---|
| app_users | UUID, логин, bcrypt, роль, баланс, даты и время последнего сброса демо | Сид, сервер демо, админские RPC, RPC сделок |
| app_sessions | UUID, user_id, SHA-256 токена, даты создания и истечения | Таблица прежней авторизации. Демо-режим её не читает и не записывает |
| simulation_sessions | Пользователь, сценарий, балансы, индекс, статус, даты, candles и market_source | API журнала и RPC симулятора |
| trades | Владелец, сессия, сценарий, актив, сторона, количество, цены, риск, статус и P&L | RPC сделок и продвижения |

~~~mermaid
erDiagram
    APP_USERS ||--o{ APP_SESSIONS : has
    APP_USERS ||--o{ SIMULATION_SESSIONS : owns
    APP_USERS o|--o{ TRADES : owns
    SIMULATION_SESSIONS o|--o{ TRADES : contains
~~~

Ссылки сделки допускают null для совместимости. У пользователя одна активная сессия на сценарий благодаря частичному уникальному индексу.

## Функции

Аргументы ниже указаны в порядке определения.

| Функция | Типы аргументов | Назначение |
|---|---|---|
| set_app_user_password | text, text, numeric, text | Установка bcrypt, баланса и роли для сида |
| authenticate_app_user | text, text | Проверка логина и пароля |
| create_app_user | text, text, numeric, text | Создание учётной записи |
| update_app_user | uuid, text, text, numeric, text | Изменение переданных полей пользователя |
| place_trade | uuid, uuid, text, text, text, numeric, numeric, numeric, integer | Открытие сделки и обновление баланса в транзакции |
| close_trade | uuid, uuid, numeric | Закрытие и расчёт P&L |
| advance_simulation_session | uuid, uuid, integer | Прежняя функция шага; текущий обработчик её не вызывает |
| advance_simulation_session_atomic | uuid, uuid | Шаг и пакетная обработка стопов в транзакции |
| restart_simulation_session | uuid, uuid, jsonb, text | Закрытие цикла и создание нового с переданным снимком |
| restart_simulation_session | uuid, uuid | Прежняя сигнатура для совместимости |
| reset_demo_account | uuid, numeric | Отменяет открытые позиции, завершает циклы и сбрасывает баланс. Время сброса отделяет текущий журнал от архивных сделок |

Типы клиентской части перечислены в [симуляторе](simulator.md#типы).

## Доступ и миграции

RLS включена, права браузерных ролей отозваны. Прикладные RPC доступны `service_role`; функция сида рассчитана на владельца. Для работы сервера схема public доступна через Data API. [Документация Supabase](https://supabase.com/docs/guides/api/securing-your-api).

Для чистого проекта используйте полную схему. Для существующего сверьте наличные столбцы и функции с [миграциями](../supabase/migrations). Порядок файлов: продвижение свечей, затем снимки и атомарный шаг. История на сервере может использовать другие имена и версии. Перед откатом сохраните копию и проверьте совместимость приложения с целевой схемой. Готовых обратных миграций в проекте нет.

## Известные ограничения

В существующих базах могут остаться старые таблицы уроков, пользователей и обратной связи. Новая схема их не создаёт. [ТЗ 2.8](../TZ-FIX-BUGS.md)
